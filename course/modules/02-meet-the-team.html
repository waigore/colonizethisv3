Meet the Team

Four specialized packages power the game — each with exactly one job.

When you play, you see the UI.
But behind it sits a team of specialists.

🎭
The Theater Troupe Metaphor

The game is like a theater troupe with four actors, each with a strict role. Models is the script. Logic is the stage manager. AI is the understudy. Map is the set designer.

Each package has exactly one job. They never talk to each other directly — only through well-defined contracts.

3

What Each Package Is Responsible For

📋

colonizethis_models

Pure data. Defines what a Player, Province, Unit, Army, Fleet, and TurnPhase look like. No logic lives here — just the shape of information.

🎬

colonizethis_logic

The rules engine. Runs the 13-phase turn cycle, resolves combat, builds PlayerView for each player, merges human and AI orders.

🤖

colonizethis_ai

The brain. Decides what AI players want to do — build armies, negotiate alliances, research tech. Feeds orders into the Logic layer.

🗺️

colonizethis_map

The set designer. Procedurally generates terrain, province boundaries, and topology. Runs once at game start, then stays quiet.

4

How They Talk to Each Other

AI can ask Logic for help. Logic can respond. But Logic never initiates. Watch:

AI
AI Planner

Hey Logic, I need to decide what to build this turn. Can you give me suggestions?

LG
Logic

Sure! Based on the current game state, your best options are: build a colony here, train an army there, or research this tech.

AI
AI Planner

Got it — I'll prioritize the colony. Thanks!

LG
Logic

No problem! Remember — I can only respond when you ask. I never initiate.

?
💡
Why This Matters

Because Logic never initiates with AI, the AI must make its own decisions. Logic can't "push" suggestions to AI or give it unfair advantages. This is how the game stays fair and deterministic.

The Golden Rule

⚠️
Architecturally Enforced, Not Just a Convention

Logic MUST NOT import AI. This isn't a style guide — it's enforced by the package structure. If you try to import AI from Logic, the code won't compile.

Why does this matter? Because if Logic could call AI, the AI could get information Logic doesn't normally have access to — making it impossible to keep the game fair.
