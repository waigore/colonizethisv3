| Key | Function |
|-----|----------|
| Esc | Bring up Game Control dialog |
| F1 | Help Briefing (Game Information on Terrain Map screen) |
| F2 | Quick Save |
| F3 | Quick Load |
| F4 | Preferences |
| F5 | Game Status |
| F6 | Turn Summary |
| F7 | Battle Reports |
| F8 | Deal and Market Book |
| F9 | Terrain Book |
| F10 | Army Book |
| F11 | Navy Book |
| F12 | Civilian Book |
| 1 | Show Transport Screen |
| 2 | Show Industry Screen |
| 3 | Show Trade Screen |
| 4 | Show Diplomacy Screen |
| 5 | Show Technology Screen |
| W | Wake all Civilian Units |
| O | Find a Sea Zone |
| P | Find a Province |
| A | Wake all Army Units |
| H | Help (Game Information on Terrain Map screen) |
| Z | Zoom in or Zoom out |
| X | Centre map on player's country |
| C | Centre map on selected unit |
| N | Wake all Naval Units |
